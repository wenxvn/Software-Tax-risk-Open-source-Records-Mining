# 公开披露候选案例边界

## 暂定样本

用友网络科技股份有限公司（600588）2023—2024 年年度报告，仅作为软件和信息技术服务业的**公开披露候选样本**。候选资格来自两份发行人披露年报的可重复哈希核验；执行 `uv run python scripts/verify_public_disclosures.py` 可复核。用户已确认该公开资料路线可以参赛；如最终提交要求书面证明，书面确认仍为 `TODO_MISSING_DATA`。

## 可以做什么

- 从已披露的合并财务报表、研发费用、合同负债、应收账款、政府补助、关联交易和所得税费用中提取公开字段；
- 计算纵向变动、会计报表内部勾稽和公开信息线索；
- 将输出限定为 `OBSERVATION`、`ANOMALY`、`POTENTIAL_RISK` 或 `NEED_TAX_REVIEW`。

## 明确不能做什么

- 不能把年报视为账簿、纳税申报表、发票、合同、订单或银行流水；
- 不能从公开披露直接推定少缴税、虚开发票或其他违法事实；
- 在没有正式政策核验、业务解释和原始证据的情况下，不能输出 `CONFIRMED_RISK`；
- 不得将该公开资料路线描述为企业内部调研的一手案例。参赛资格边界仍需向指导老师或组委会书面确认。
