# 甲软件和信息技术服务企业税收风险管控案例

## 基于两期公开年报与官方政策的可复现观察（初稿）

> 版本状态：`PUBLIC_DISCLOSURE_DRAFT`。本稿不是企业内部审计报告，不确认任何税务违法或少缴税事实。所有可量化结果均由代码输出；资料不足处保留 `TODO_MISSING_DATA`。

## 一、案例边界与资料来源

本案例选取一家软件和信息技术服务企业的两个年度公开年报作为研究输入。两份 PDF 已与发行人公开下载链接进行 SHA-256 一致性核验，具体文件、期间、页数和哈希见 `docs/research/yonyou_annual_report_verification.csv`。

公开年报可支持财务报表、研发费用、合同资产与合同负债、应收账款、政府补助、应交税费和现金流量等公开字段的纵向观察；但不能替代企业账簿、纳税申报表、合同、发票、订单、资金流水、研发辅助账或访谈记录。因此，本案例的结论上限为 `OBSERVATION`。

## 二、分析方法与可复现路径

1. 使用 `scripts/verify_public_disclosures.py` 验证年报来源与本地文件哈希。
2. 使用 `scripts/extract_public_financial_fields.py` 从两期合并财务报表及附注提取公开字段，并保留来源文本、页码和代码血缘。
3. 使用 `scripts/screen_public_indicators.py` 计算纵向描述性指标；全部指标采用“本期字段 ÷ 本期营业收入”的透明公式，不设置主观风险阈值。
4. 使用 `scripts/collect_policy_candidates.py` 归档官方政策网页、文本和适用边界。

计算结果在 `outputs/tables/yonyou_public_financial_fields.csv` 与 `outputs/tables/yonyou_public_indicator_observations.csv`；字段可得性、政策与候选指标覆盖分别见 `docs/research/` 下相应 CSV。

## 三、公开资料下的候选观察

### （一）收入、回款与合同履约线索

以“销售回款/营业收入”“应收账款/营业收入”“合同资产/营业收入”“合同负债/营业收入”形成公开纵向观察。这些比率只用于提示后续核验收入确认、履约、开票与申报期间是否一致；它们不能证明增值税计税义务发生时间或销项税申报存在问题。

需补强的资料：合同、验收或履约资料、销项发票、增值税申报表、回款明细及期后回款。增值税基础政策候选为 `POL-VAT-2016-36`，但具体服务性质、纳税人资格、计税方法和税率仍为 `NEED_TAX_REVIEW`。

### （二）研发费用线索

以“研发费用/营业收入”进行两期公开观察。年报研发费用是会计披露字段，不等同于企业所得税加计扣除的可归集金额，也不表示企业已享受或不应享受优惠。

需补强的资料：研发项目书、研发辅助账、人员工时、费用明细、企业所得税申报表及 A107012。政策候选 `POL-CIT-RD-2023-07` 和 `POL-CIT-RD-2023-11` 的期间适用性已在官方来源中核验；实际资格、归集口径和申报处理仍为 `TODO_MISSING_DATA`。

### （三）政府补助线索

以“计入损益政府补助/营业收入”进行公开纵向观察。年报列示的政府补助不等同于企业所得税不征税收入，也不能据此判断是否存在税会处理差异。

需补强的资料：资金拨付文件、专项管理办法或要求、单独核算资料以及企业所得税申报表。根据 `POL-CIT-GOV-2011-70`，专项用途财政性资金的税务处理需要同时满足法定条件；当前无法核验这些条件。

### （四）税费综合观察

“税金及附加/营业收入”“支付各项税费/营业收入”和“应交税费/营业收入”仅反映合并财务报表或现金流量表的汇总口径，无法拆分增值税、企业所得税、印花税等具体税种，也不能识别正常的跨期、汇算清缴或会计调整因素。

需补强的资料：各税种明细账、纳税申报表、缴款书和计税底稿。

### （五）印花税与关联交易资料覆盖

公开年报没有逐份应税合同、印花税税源明细表、关联交易定价资料或资金流水。相应候选指标状态为 `TODO_MISSING_DATA`，当前结论为 `NO_CONCLUSION`。

印花税资料补强包括应税合同台账、税源明细表、申报表和缴款书；关联交易资料补强包括交易明细、定价资料、合同、发票、资金流水和企业所得税申报表。

## 四、假阳性排除原则

- 回款、应收账款、合同资产和合同负债的变动可能来自客户结算周期、履约安排、项目验收、预收款或商业信用政策；必须以业务资料排除。
- 会计研发费用与税法可加计扣除研发费用的范围、归集和留存资料要求不同；不能用会计金额直接计算税收优惠。
- 政府补助的会计确认与企业所得税不征税收入条件不同；必须取得拨付、管理和单独核算证据。
- 税费汇总字段含多种税费和跨期影响，不能反推某一税种的申报结果。
