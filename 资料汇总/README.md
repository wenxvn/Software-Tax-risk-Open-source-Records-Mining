# 税收风险大赛资料汇总

本资料包面向校赛准备，按以下目录组织：

- `01_官方规程与规范/`：2026 年官方规程、案例编写规范及关键条款速查。
- `02_历届获奖信息/`：高校官网公开的 2024—2025 年获奖/赛事报道、案例题目和 2025 年校内赛获奖名单。
- `03_报告模板与写作/`：可直接复制的案例报告模板、校赛推进清单。
- `04_政策与分析参考/`：国家税务总局、12366、国家统计局等政策和数据入口。
- `05_来源索引/`：每份资料的原始链接、用途和使用说明。

## 关于“获奖作品”

目前公开渠道主要提供获奖新闻稿、案例题目和获奖名单，完整获奖报告通常受版权、企业隐私和组委会授权限制，未发现可合法公开下载的完整作品。因此目录中保存的是可核验的公开报道原文和可借鉴的案例题目，不把新闻稿冒充完整获奖作品。官方规程提到可参考《中国财政经济出版社 2026 年出版的〈全国本科院校税收风险管控案例大赛精选案例与点评（2025）〉》，可通过学校图书馆或正规渠道查阅。

## 快速开始

1. 先阅读 `01_官方规程与规范/2026规程关键条款速查.md`，再打开两份 PDF 原文。
2. 用 `03_报告模板与写作/税收风险管控案例报告模板.md` 建立初稿。
3. 参照 `02_历届获奖信息/` 中南开、天津财经、广东财经等报道，比较选题、风险分析和答辩要点。
4. 用 `05_来源索引/资料索引.md` 保存你新增政策、数据和网页来源。
