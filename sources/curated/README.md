# Curated Research Pack

本目录是从 `资料汇总/` 筛选并复制的竞赛研究资料，以及本轮保存的公开入口页面。它服务于选题和方法设计，不等于企业证据，也不等于完整获奖作品。

## 目录

- `competition/`：2026 官方规程、案例编写规范和关键条款。
- `benchmarks/`：高校官网公开的历届获奖/赛事报道，仅用于比较案例题目和评审关注点。
- `templates/`：报告模板和校赛推进清单。
- `policy_channels/`：官方政策和行业数据入口。
- `open_data/`：公开年报/公告检索渠道、候选上市公司和开源资料研究方法。
- `manifest.csv`：文件 SHA256 与来源说明。

## 证据边界

公开年报和公告只能支持“公开信息下的风险线索”。没有企业原始申报表、账簿、合同、发票、资金和访谈，不得确认违法或生成 `CONFIRMED_RISK`。网页抓取结果必须以原始公告 PDF/HTML 和访问日期为准。
