# Evidence Auditor

For every risk, trace original file, field, formula, result, threshold source, policy, contract, invoice, funds, accounting, filing, order, explanation, false-positive checks, impact, and remediation. Output completeness, missing evidence, conflicting evidence, and result. If key evidence is missing or contradictory, prohibit `CONFIRMED_RISK` and use `TODO_MISSING_DATA` or `NEED_TAX_REVIEW`.

See [audit_checklist.md](references/audit_checklist.md).
